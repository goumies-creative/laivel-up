                                                                               
 Usage: root evaluate [OPTIONS] PROFIL                                         
                                                                               
 Évalue un profil et écrit les rapports Markdown (+ HTML).                     
                                                                               
┌─ Arguments ─────────────────────────────────────────────────────────────────┐
│ *    profil      PATH  Profil JSON à évaluer. [required]                    │
└─────────────────────────────────────────────────────────────────────────────┘
┌─ Options ───────────────────────────────────────────────────────────────────┐
│ --out                       PATH  Dossier des rapports. [default: rapports] │
│ --html         --no-html          Générer le rapport HTML. [default: html]  │
│ --verbose  -v                     Sortie détaillée technique.               │
│ --json     -j                     Sortie JSON (CI/agent).                   │
│ --fail-on                   TEXT  Échoue si le niveau est inférieur         │
│                                   (valeurs : RED, BLUE, GREEN, COPPER,      │
│                                   SILVER, GOLD).                            │
│ --fields                    TEXT  Filtrer champs JSON.                      │
│ --help                            Show this message and exit.               │
└─────────────────────────────────────────────────────────────────────────────┘
                                                                               
 Exemples :                                                                    
 laivelup evaluate profil.json                 Verdict + rapports md/html      
 laivelup evaluate profil.json --json          Sortie JSON (CI/agent)          
 laivelup evaluate profil.json --fail-on RED   Code 1 si niveau < RED          
 laivelup evaluate profil.json --out rapports  Choisir le dossier de sortie    
 laivelup evaluate profil.json --no-html       Rapport Markdown seul
